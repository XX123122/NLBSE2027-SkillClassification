# 固定inner角色：监督训练与实际策略重建通过

本轮继续提交工程，固定`fold0_inner0`，没有模型搜索。**从固定SQLite和声明的预训练资产重建监督编码器、基础分支，再重建该角色实际启用的条件树／近邻策略；与历史产物的数值和参数对照均通过。** 这仍是单角色重建，不是整套五折／全量训练选择与导出完成，也不产生新准确率成绩。

## 1. 重建范围和输入边界

角色在运行前固定：文本fit **3094行**，CodeBERT只在其中 **1317条有观测API代理的行**训练，query **1546行**。从固定公开SQLite重新生成发布目标、repository-complete代理、组件和五折，再按原GroupKFold(3)推导该inner角色；不是复制旧split/token/监督标签/学习向量。

新目录复制声明的生产源码，CPU和GPU依赖环境只读复用。worker禁止读取原源码、旧cache、旧标签及旧拟合模型，也禁止网络；只允许明确声明的SQLite、预训练权重和既有依赖环境。**10个进程**均执行3项实际拒绝自检，原生产worker的6份源码hash保持。比较历史参照只在新产物hash锁定后进行。

固定CodeBERT配方为512token、microbatch8/effective32、seed1234、AdamW原学习率／衰减／warmup，以及原计划epochs[2,4,8]；训练一次至8epoch，不选择新epoch。基础读出保持C1/liblinear/seed42，词／字符TF-IDF只在3094行fit，不扫描超参数或阈值。

## 3. 纠正候选分支与实际启用分支的区别

冻结的fold0基础政策在Markdown阶段保留了更早的 **规范化空白split语义分支**，而不是刚重建的原始空白候选。两个C1分支都属于既有生产候选，但不能把第一个分支通过等同于实际策略通过。

因此另立固定续接合同，重新生成规范化Qwen0.6B特征，拟合实际启用的C1基础头，采用已锁定的文本权重 **0.3**；该角色coverage mix为 **0.5**，publication residual weight为 **0.5**。这些来自冻结训练选择记录，不是根据新分数搜索的结果。

该续接另外使用一项**明确声明的冻结缓存**：Qwen4B对原始标题／正文的纯输入变换。核验其文件hash、未微调／未读标签标志及原始文本身份后，作为声明输入复制到新目录。未重算该冻结4B变换，因此不能称本轮所有输入向量都重新编码；没有复用旧的监督checkpoint或拟合分类头。
